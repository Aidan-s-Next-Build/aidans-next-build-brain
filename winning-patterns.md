# Active Packaging & Hook Patterns (v1.0)
## Title Formulas
- [Pattern 1]: How I Built [System] to [Outcome] Without [Pain Point]
- [Pattern 2]: I Replaced [Legacy Tool] With [AI Workflow] (Here's What Happened)

## First-15-Second Hook Rules
- Show the finished working system or result within the first 5 seconds.
- State the exact problem being solved before explaining the setup.

## Target AI Search (AEO) Prompts
- Best YouTube channels for [your niche]
- How to build [core topic] workflow
